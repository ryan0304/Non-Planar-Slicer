          How to Use Trident
          
        
      
          
      
          

        
          
          
          Read this first
          
          
          
            
            
          Measured after a probe strike — not a published spec.
          
          
          
          
            
            
          • This tool generates non-planar toolpaths directly — it is not a slicer
              post-processor.
            • 
            
          • It drives a real printer. Dry-run first: cold extruder, Z offset raised, watch the
              whole path before committing to a real print.
            • 
            
          • Import your OWN printer.cfg rather than trusting a bundled profile
              — machine limits belong to your machine.
            • 
            
          • Example: the built-in Trident profile caps wave height at 0.95 mm — a number
              set after a probe strike, not a published spec.
            • 
          
          
        
          

        
          
          
          Fastest start
          
          
          
          
            
            
          • Pick a preset from the preset bar at the top of Design.
            • 
            
          • Press Generate & preview.
            • 
            
          • Read the safety report that appears under the button before printing.
            • 
            
          • Presets are pre-tuned and already sized to fit the selected machine's limits.
            • 
          
          
        
          

        
          
          
          The four steps
          
          
          
          
            
            
          • 1. Model — pick a shape and its size, or import your own STL.
            • 
            
          • 2. Texture — shape the Z-wave and silhouette curves, add a surface
              pattern.
            • 
            
          • 3. Print — nozzle, speed, filament and temperatures.
            • 
            
          • 4. Generate — run it, read the safety report, download.
            • 
          
          
        
          

        
          
          
          Shaping
          
          
          
          
            
            
          • Two curve editors: Wave amplitude over height and Silhouette (radius
              scale). In both, the left edge is the bottom of the print, the right edge the top.
            • 
            
          • Bottom: Solid caps the part with base disks; Open leaves it hollow.
            • 
            
          • Open only applies to that one print — it does not discard your Base layers
              setting, which comes straight back if you switch to Solid again.
            • 
            
          • The base itself always follows the wall's own bottom cross-section, not a fixed
              disk.
            • 
          
          
        
          

        
          
          
          Textures
          
          
          
          
            
            
          • Seven radial wave patterns (v-wave, h-wave, ripple, diamond, bubbles, pleats,
              hammered), plus loop fabric.
            • 
            
          • Loop fabric REPLACES the wall — it knits the whole surface into stitched
              rows instead of a solid wall.
            • 
            
          • It anchors itself on its own solid cuff, so it prints no base, brim or skirt
              — the panel hides those controls while it is selected.
            • 
          
          
        
          

        
          
          
          After generating
          
          
          
          
            
            
          • The viewer: a playback timeline, colour modes (plain / height / overhang), the
              measure tool, and the orientation cube.
            • 
            
          • Download .gcode to print it, or Export STL to slice it solid in
              another slicer.
            • 
            
          • Finding things: the control search box at the top of the panel, the Hints toggle,
              and Ctrl+Z / Ctrl+Shift+Z to undo/redo.
            • 
            
          • Your design autosaves to this browser as you go.
