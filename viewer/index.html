    Cooling & flow

    Overhang flow boost 0
    Compensates under-extrusion on outward-leaning walls. 0 = off, higher = more extra flow on overhangs.
    Fan min 100%
    Fan max 100%
    The part-cooling fan runs between these two speeds, picked by how far the wall leans: min on a vertical wall, rising to max where it leans 45° outward or more (less material sits below an overhang to carry heat away). Set both to the same value for a constant fan speed.
    Note: the lean comes from the Silhouette curve. A straight (cylindrical) silhouette never leans, so the print stays at min the whole way and max has nothing to act on — flare the silhouette to see the fan ramp up.
    Fan off for first layers
    Total layers (base + wall) to keep the fan off, counted from the very start of the print. A solid base already prints fan-off on its own — this only adds MORE wall turns beyond that if set higher. 0 = today's default (off through any base, or the wall's first turn if there's no base).
